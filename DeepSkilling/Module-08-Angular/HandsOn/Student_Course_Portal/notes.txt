ANGULAR PROJECT FILE NOTES

1. angular.json
Angular CLI workspace configuration file. It contains settings for building, serving and testing the Angular application, including assets, styles, scripts and production budgets.

2. tsconfig.json
Main TypeScript configuration file for the Angular workspace. It defines compiler options and TypeScript settings used by the project.

3. tsconfig.app.json
TypeScript configuration specifically used for compiling the Angular application source files.

4. package.json
Contains project metadata, npm scripts and the dependencies required by the Angular application.

5. src/main.ts
The entry point of the Angular application. It bootstraps the root App component and application configuration.

6. src/app/app.config.ts
Contains application-level configuration and providers such as Angular Router configuration.

7. src/app/app.ts
Defines the root Angular component of the application using the @Component decorator.

8. src/index.html
The main HTML document loaded by the browser. It contains the root <app-root> element where Angular renders the application.
