\# Continuous Integration and Continuous Delivery







\## Continuous Integration (CI)







Continuous Integration is the practice of automatically building and testing code whenever developers commit changes.







\### Benefits







\- Detect bugs early



\- Frequent integration



\- Automated testing



\- Better collaboration







\---







\## Continuous Delivery (CD)







Continuous Delivery prepares software for deployment automatically after successful testing.







\### Benefits







\- Reliable releases



\- Faster deployment



\- Reduced manual work







\---







\## Continuous Deployment







Continuous Deployment automatically deploys every successful build directly into production without manual approval.







\---







\## CI vs CD







| CI | CD |



|----|----|



| Builds and tests code | Deploys application |



| Detects errors early | Delivers software faster |



| Developer focused | Operations focused |
