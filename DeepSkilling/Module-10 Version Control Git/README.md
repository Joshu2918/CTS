\# Module 10 – Version Control (Git)



\## Overview



This module introduces Git, a distributed version control system widely used in software development. It covers Git fundamentals, repository management, branching strategies, merging, remote repositories, and collaboration workflows using GitHub.



\## Learning Objectives



\* Understand the fundamentals of version control systems.

\* Learn the architecture and workflow of Git.

\* Create and manage Git repositories.

\* Track file changes using Git.

\* Work with branches and merge changes.

\* Connect local repositories to remote repositories.

\* Push and pull changes using GitHub.

\* Understand collaborative development using feature branches and pull requests.
