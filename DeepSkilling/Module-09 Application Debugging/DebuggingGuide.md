\# Debugging Guide



\## Objectives



\- Debug Angular applications.

\- Inspect DOM elements.

\- Analyze HTTP requests.

\- Set breakpoints.

\- Inspect variables.



\## Tools



\- Google Chrome DevTools

\- Visual Studio Code

\- Angular CLI



\## Activities Performed



\- Started Angular using ng serve.

\- Inspected HTML elements.

\- Verified API requests.

\- Monitored network traffic.

\- Configured VS Code debugger.



\## Outcome



Successfully analyzed the Angular application and identified frontend behavior using browser developer tools.
