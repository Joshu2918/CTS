\# Module 11 - DevOps and CI/CD



\## Overview



This module introduces the fundamentals of DevOps and Continuous Integration/Continuous Delivery (CI/CD). It focuses on understanding DevOps culture, automation, collaboration between development and operations teams, and popular CI/CD tools used in modern software development.



\## Learning Objectives



\- Understand the concept of DevOps.

\- Learn the DevOps lifecycle and best practices.

\- Understand Continuous Integration (CI) and Continuous Delivery/Deployment (CD).

\- Compare CI and CD.

\- Explore popular DevOps tools such as Jenkins, GitHub Actions, GitLab CI/CD, and CircleCI.

\- Understand how CI/CD pipelines automate software development and deployment.
