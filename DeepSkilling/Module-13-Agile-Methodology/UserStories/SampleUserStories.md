\# Sample Agile User Stories



\## User Story 1



As a customer,



I want to log into the application,



So that I can access my account securely.



\### Acceptance Criteria



Given the user enters valid credentials



When the Login button is clicked



Then the user should be redirected to the dashboard.



\---



\## User Story 2



As an administrator,



I want to add new products,



So that customers can purchase them.



\### Acceptance Criteria



Given the administrator is logged in



When product details are submitted



Then the product should be stored successfully.



\---



\## INVEST Principle



\- Independent

\- Negotiable

\- Valuable

\- Estimable

\- Small

\- Testable
