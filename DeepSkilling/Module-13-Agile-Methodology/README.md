\# Module 13 - Agile Methodology



\## Overview



This module introduces Agile software development practices, Scrum framework, estimation techniques, sprint planning, velocity tracking, and user story creation.



\## Learning Objectives



\- Understand Agile principles and values

\- Compare Agile and Waterfall

\- Learn Scrum roles, ceremonies, and artifacts

\- Understand Story Points and Planning Poker

\- Learn Sprint Planning and Velocity

\- Write effective User Stories

\- Create Acceptance Criteria



\## Topics Covered



\- Agile Manifesto

\- Scrum Framework

\- Sprint Planning

\- Story Points

\- Planning Poker

\- Velocity

\- Burndown Charts

\- User Stories

\- INVEST Principle

\- Acceptance Criteria
