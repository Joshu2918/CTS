\# Module 12 - Containerization using Docker



\## Overview



This module provides an introduction to Docker and containerization concepts. It covers Docker architecture, Docker Engine, Docker Images, Docker Containers, Docker Compose, storage, networking, and container orchestration.



\## Objectives



\- Understand Docker fundamentals

\- Learn commonly used Docker commands

\- Understand Docker Images and Containers

\- Learn Docker Compose basics

\- Understand Docker Storage and Networking

\- Learn the basics of Container Orchestration
