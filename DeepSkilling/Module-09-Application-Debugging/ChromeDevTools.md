\# Chrome DevTools



\## Features Used



\- Elements

\- Network

\- Fetch/XHR

\- Sources

\- Console



\## Steps



1\. Press F12.

2\. Open Network tab.

3\. Reload application.

4\. Inspect GET /api/Students.

5\. Verify Status Code 200.

6\. Inspect DOM using Elements panel.



\## Learning



Chrome DevTools helps inspect requests, HTML elements, JavaScript execution and application performance.
